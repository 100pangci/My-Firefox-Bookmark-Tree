# My-Firefox-Bookmark-Tree

## 从 Firefox 书签导出 Tree

项目内提供了一个 Python 脚本：`src/extract_bookmark_tree.py`

它可以：

- 读取 Firefox 导出的 `output/bookmarks.html`
- 提取 `书签工具栏` 的文件夹层级
- 忽略具体书签链接，仅保留目录结构
- 按下面示例中的 Tree 文本格式输出

### 用法

直接输出到终端：

```bash
python src/extract_bookmark_tree.py
```

指定输入文件：

```bash
python src/extract_bookmark_tree.py -i output/bookmarks.html
```

指定要提取的根目录名称：

```bash
python src/extract_bookmark_tree.py -r 书签工具栏
```

输出到文件：

```bash
python src/extract_bookmark_tree.py -o output/tree.txt
```
